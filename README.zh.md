# dsh-sketchpad · DSH 画板

[English](README.md) | 中文

给 [DeepSeek Harness](https://github.com/deepseek-ai/dsh) 加一块画板：手写公式、画示意图或随手记，画完把图片作为附件发出去。

<img src="docs/images/float.png" alt="浮动画板：手写的积分公式" width="100%">

## 功能

- **浮动画板**：输入框左侧铅笔按钮，横版 1600×1000。`Esc`、`×`、点遮罩、双击空白都能关闭，关闭即把画面保存为附件。
- **侧栏画板**：右侧栏竖版 1000×1333，笔画与附件独立。
- **只在明确操作时生成图片**：绘制过程不编码；关闭浮窗或点「插入」时才导出 PNG。
- **导出裁切**：按笔画包围盒 + 26 px，小图最多放大 2.5 倍（长边约 900 px）。
- **工具**：水笔、直线、箭头、橡皮（圆形光标）；笔宽 4 / 7 / 12 px；黑、红、蓝；`Shift` 吸附 0°/45°/90°。
- **撤销、立即清空、单一触点**：清空无二次确认；第二根手指不会混入当前笔画。
- **快捷键**：`B` `L` `A` `E`、`[` `]`、`Ctrl/Cmd+Z`、`Esc`。

## 安装

需要 DSH 0.2.1-rc.2 或更新版本。

```sh
dsh plugin --profile web add dsh-sketchpad
```

重启 `dsh web`（热安装后刷新页面也可以）。

## 使用

1. 点输入框左侧铅笔按钮（或右侧栏的 **画板**）。
2. 画。
3. 关闭浮窗（自动保存为附件）或点 **插入**。
4. 发送。

浮窗的 **插入** 会冻结画面、清空画板并关闭窗口；侧栏的 **插入到输入框** 保留标签页，方便接着画下一张。

## 权限与数据

不发网络请求，也不读取消息内容。只使用宿主的草稿附件 API、会话输入状态、右侧栏 API，以及 `localStorage` 记笔色和粗细。画板只在页面内存里，PNG 在浏览器里生成。

## 限制

没有压感和掌托识别；两块画板内容独立；尺寸固定；清空不可撤销；刷新页面会清空画板。
