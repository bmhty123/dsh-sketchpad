# dsh-sketchpad · DSH 画板

[English](README.md) | 中文

给 [DeepSeek Harness](https://github.com/deepseek-ai/dsh) 加一块画板：手写公式、画示意图或随手记，画完把图片作为附件发出去。

<img src="docs/images/board-light.png" alt="浮动画板：手画的两个方框加箭头，工具栏有水笔、直线、箭头、橡皮、笔宽、颜色、清空、撤销、重做和完成" width="100%">

## 功能

- **入口**：输入框「+」菜单里的「画板」（也可以直接输入 `/sketchpad`），以及右侧栏的「画板」页签。
- **浮动画板**：横版 1600×1000。`Esc`、`×`、点遮罩、双击空白都能关闭；**关闭只是收起窗口**，
  要把画面放进消息请点「完成」。
- **侧栏画板**：右侧栏竖版 1000×1333，笔画与附件独立。
- **只在明确操作时生成图片**：绘制过程不编码；点「完成」时才导出 PNG。
- **导出裁切**：按笔画包围盒 + 26 px，小图最多放大 2.5 倍（长边约 900 px）。
- **工具**：水笔、直线、箭头、橡皮（圆形光标）；笔宽 4 / 7 / 12 px；黑、红、蓝；`Shift` 吸附 0°/45°/90°。
- **撤销、立即清空、单一触点**：清空无二次确认；第二根手指不会混入当前笔画。
- **快捷键**：`B` `L` `A` `E` 换工具，`1` `2` `3` 换色，`[` `]` 换笔宽，`Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 重做，`Enter` 完成，`Esc` 关闭浮窗。
- **中英文**：界面文案跟随宿主语言（读 `<html lang>`），中文/英文各自一套。
- **每次打开一块新画布**：上一张不销毁，只是挪进了撤销栈 —— 空白画板上点**撤销**就能回去，重做又是空的。

## 安装

需要 DSH 0.2.1-rc.2 或更新版本。

```sh
dsh plugin --profile web add dsh-sketchpad
```

重启 `dsh web`（热安装后刷新页面也可以）。

## 使用

<img src="docs/images/board-menu.png" alt="输入框「+」菜单里的画板入口" width="100%">

1. 打开输入框「+」菜单里的 **画板**（也可以输入 `/sketchpad`，或用右侧栏的 **画板** 页签）。
2. 画。
3. 点 **完成**（或直接按 Enter）把画面挂成附件；只点 × 关闭不会动输入框。
4. 发送。

浮窗的 **完成** 会冻结画面、清空画板并关闭窗口；侧栏的 **完成** 保留标签页，方便接着画下一张。
关掉浮窗后再打开是一块新画布；上一张没有丢，点 **撤销** 就回来了。

## 权限与数据

不发网络请求，也不读取消息内容。只使用宿主的草稿附件 API、会话输入状态、右侧栏 API，以及 `localStorage` 记笔色和粗细。画板只在页面内存里，PNG 在浏览器里生成。

## 限制

没有压感和掌托识别；两块画板内容独立；尺寸固定；清空不可撤销；刷新页面会清空画板。
